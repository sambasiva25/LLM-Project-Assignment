Slovenia IMF Report Analysis
This project analyses Slovenia’s 2024 Article IV Consultation report using summarisation, financial indicator extraction, vector RAG, automated evaluation and a four-panel dashboard.
How to Run
1. Open the notebook in Google Colab.
2. Download IMF Country Report 24/120 and upload it as Slovenia_2024.pdf.
3. Add your Gemini API key to Colab Secrets as KEY and enable access.
4. Run all 14 code cells in order. Internet access and API credits are required.
Outputs
Results are saved in slovenia_project/results/. Cached responses and embeddings are stored in slovenia_project/cache/.
Evaluation
Generated outputs and judge scores require source verification. Unsupported indicators remain null with explanations.
